Supporting work for agenix-rekey.  The secret generators live in
[[https://github.com/LoganBarnett/agenix-rekey-generators][agenix-rekey-generators]], and ~nixos-configs/secrets.nix~ imports its module.
Only a generator that cannot leave this repository is declared here.

* Secret generation

Generated secrets land in ~secrets/generated/~ unless ~rekeyFile~ is set.
Secrets issued from external sources go under ~secrets/issued~.
