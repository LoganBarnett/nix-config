Documentation for the option sets this repository declares.  The options are
largely generated, with small amounts of prose outside of the =Options=
subsection inside them.

* Authoring

** Rendering one option set

~nix-options-org~ evaluates an option prefix on a host through the flake's
~lib.optionsDocList~ and prints it as an org description list.  The block
below wraps it so an Options section can call it with ~#+call~.  The result
lands in a drawer, which org-babel can replace, so ~C-c C-c~ on a ~#+call~
line refreshes that one section.

The tool comes from the devShell.  direnv provides it in a terminal and envrc
provides it in Emacs.

#+name: nix-options
#+begin_src sh :var prefix="" :var host="scandium" :dir .. :results drawer :exports none
nix-options-org --host "$host" --prefix "$prefix"
#+end_src

** Regenerating every Options section

~C-c C-c~ here re-runs every ~#+call~ line in this file.

#+begin_src emacs-lisp :results none :exports none
(org-babel-map-call-lines nil (org-babel-lob-execute-maybe))
#+end_src

The same thing from a shell in the devShell, for a check that needs no window:

#+begin_src sh :results none :exports code
emacs --batch -l org \
  --eval '(setq org-confirm-babel-evaluate nil)' \
  --eval '(org-babel-do-load-languages (quote org-babel-load-languages) (quote ((shell . t) (emacs-lisp . t))))' \
  docs/nix-options.org \
  --eval '(org-babel-map-call-lines nil (org-babel-lob-execute-maybe))' \
  -f save-buffer
#+end_src

** Adding an entry

1. Add a heading under Nix Options, lexicographically placed, and named after
   the option prefix.
2. Resist the urge to write a lot of prose, since the options document virtually
   everything you'd want to write here.
3. End with a ~Options~ subsection holding one line,
   ~#+call: nix-options(prefix="<prefix>")~.  Add ~host="<host>"~ when the
   default host does not import the module.
4. Run the call and commit the drawer it produces.
